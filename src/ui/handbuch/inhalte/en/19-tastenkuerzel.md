# Keyboard shortcuts

Every command can be given a key, and every assigned key can be changed. The manual shows you **your**
assignment everywhere, not the factory one.

## Overview {#kuerzel-uebersicht}

{{befehl:extras.tastenkuerzel}} opens a list of all commands with the current assignment, sorted into
groups – for looking things up and for printing.

## Assigning your own shortcuts {#kuerzel-vergeben}

1. Open the program settings ({{befehl:extras.einstellungen}}) and go to the section **Keyboard
   shortcuts**.
2. Find the command in the list.
3. Click in the field and **press** the key combination you want. It is accepted as you type it.
4. If the key is already assigned, the program reports the conflict, and you decide who keeps it.

Resetting is possible for a single shortcut, or for all of them at once (**Reset all to default**).

{{befehl:werkzeug.schaltverbindung}} has no shortcut of its own. It shares its key with
{{befehl:werkzeug.leitung}}: in the floor plan it opens the cable, and in the schematic it opens the
wire, because there are no cables in a schematic. If you change the shortcut of the cable, the change
applies to both. Tools that do not suit the type of drawing do not open at all from their key.

## Keys that cannot be assigned {#feste-tasten}

Some keys belong to the tools themselves, and are therefore locked:

| Key | Belongs to |
|---|---|
| Esc | Cancelling the current action |
| Enter | Finishing polyline, trunk and hatching |
| Del, Backspace | Deleting the selection |
| + and − | Number of corners for a polygon, wall thickness in the wall tool |
| Tab | Moving the focus; while drawing, switching between the dimension fields |

A hint also appears when a key is free but already used within a tool. **M**, for example, switches the
type in the hatching tool.

> The Command key (⌘) on the Mac and the Ctrl key on Windows count as the same key: a shortcut such as
> Ctrl+S works on both systems as usual.
