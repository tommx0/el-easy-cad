# Licence, updates and help

## Program version and licence {#lizenz}

{{befehl:hilfe.ueber}} shows the version that is running – the same number appears at the top of
the header and at the top of this manual – and the licence under which el.easy.CAD Community is
published. “Licence text…” there and in {{befehl:hilfe.meine-lizenz}} shows the complete, binding
licence text. It also ships with the program as the file `LICENSE`, the licences of the third-party
libraries as `LICENSES.md`.

:::nur-desktop
**Non-commercial use:** el.easy.CAD Community is free for any non-commercial use – with all
features and no time limit. It is licensed under PolyForm Noncommercial 1.0.0. The header then
shows “Non-commercial use”, and every printout, every PDF, every Excel workbook and every IFC
export carries a note to that effect: on plan pages a small stamp at the top right and a line in
the small print. The drawing area itself stays clear. At the first start and after every update, a
short notice explains what this means.

**Supporter licence:** For business or professional use you need a supporter licence. You receive
it as a file when you support the project (see [Support the project](#unterstuetzen)).
{{befehl:hilfe.meine-lizenz}} shows your licence: who it is issued to, your supporter tier, whether
it permits commercial use and the period for which it is valid. You also install the licence file
there.

- If your tier permits commercial use, the stamp and the note disappear. Instead, the header and
  the small print name you as “Official supporter of the project” with your tier.
- If it does not permit commercial use, both appear: your tier and the note on non-commercial
  use.
- When the licence expires, non-commercial use applies again; nothing is locked. A notice at
  start-up states the expiry date.

Drawings that you created without a commercial licence keep a note about it – even later, with a
licence. When you open such a drawing, a short notice appears; the drawing does not get a stamp.
:::

:::nur-cloud
The use is governed by your company's contract; you do not need a separate licence file. If the
contract period runs out, a notice points this out in good time.

{{befehl:hilfe.impressum}} shows the publisher's imprint.
:::

{{befehl:hilfe.lizenzen}} lists the third-party libraries used, with their licences.

:::nur-desktop
## Support the project {#unterstuetzen}

{{befehl:hilfe.unterstuetzen}} opens the project's supporter page in your browser. There you choose
a tier; the page states which tiers permit commercial use. You then receive the licence file from
the project. The same links appear in the notice at start-up, in “My licence” and under
{{befehl:hilfe.ueber}}. The program itself transmits nothing – it only opens the page.
:::

:::nur-cloud
## New versions {#updates}

The cloud version is updated on the server; you do not need to install anything. If a newer version
is available, the program notifies you – {{befehl:hilfe.neu-laden}} fetches it immediately.
:::

:::nur-desktop
## Updates {#updates}

The program does not check for new versions by itself. New versions are available for download on
the project page; you install them just like the first installation. Your projects are kept.

Please install updates promptly once you hear about a new version. They fix errors and close
security gaps.
:::

## Privacy {#datenschutz}

The program does not transmit any data: your projects and settings stay on your computer, and
there is no telemetry and no analytics. {{befehl:hilfe.ueber}} says so too, together with the link
to the project page.

## Error log {#fehlerprotokoll}

If something is wrong, the error log helps: {{befehl:hilfe.fehlerprotokoll}} shows all recorded
errors with their time and context.

:::nur-cloud
From there you send the extract to the manufacturer as feedback – with one click, without copying
anything out. For general feedback and requests, use the feedback button at the top left of the
header.
:::

:::nur-desktop
There is no feedback function in the program. Download the extract as a file and attach it to a
bug report (“issue”) on the project page.
:::

## About this manual {#diese-anleitung}

{{befehl:hilfe.handbuch}} opens the manual; it describes exactly the version that runs on your
computer. **F1** from an active tool jumps straight to the matching section.

- **Topic tree** on the left: a click on a chapter opens it and expands its sections; a click on a
  section jumps there. Cross-references in the text lead just as directly to the place they name.
- **Search field** at the top: from two letters onwards, a list of hits replaces the topic tree –
  one hit per section, with the place where the term occurs. Upper and lower case make no
  difference, and umlauts match their spelling, so “ue” also finds “ü” and vice versa. Menu commands
  are found under the name that appears in the menu. A click on a hit opens the section; clear the
  field and the topic tree reappears.

Use “Print / as PDF” at the bottom left to output the whole manual.
